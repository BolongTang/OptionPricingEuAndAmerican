DRAFT SENTENCES CURRENTLY IN THE TEX FILE (placeholders to rewrite in your own words, one per line)
  S1. The classes that were written by hand (\texttt{BrownianMotion},
      \texttt{symmetric\_random\_walk}, \texttt{CRRBinomialModel}, \texttt{CRRTree} and the two GBM
      simulators) are used exactly as written.
  S2. Every extension is a subclass or a new function placed after them and marked \texttt{[EXT]} in
      the notebook, so each added result can be traced back to the original code it builds on.
  S3. A single notebook produces every figure, table and number in this report, all random numbers
      are seeded, and the numbers quoted in the text are read from a file generated by the notebook.
  S4. A complete run takes about ten minutes on one core.
  S5. The scope is deliberately narrow: constant volatility, a constant interest rate and no
      dividends, except in the one section where a dividend yield is introduced on purpose.
  S6. These are the assumptions under which every method in the report can be compared against an
      exact or near-exact answer.
  S7. Full derivations are collected in Appendix~\ref{app:derivations} and the code listing is in
      Appendix~\ref{app:code}.
